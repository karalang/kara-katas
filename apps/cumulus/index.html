Result

The same kernels run here and in the command-line build — one Kāra source, two targets. The node harness requires the WebAssembly result to be byte-identical to the native binary's, so this page is not a reimplementation of the pipeline; it is the pipeline.

Supported input: BITPIX=16, NAXIS=2 FITS with BZERO/BSCALE — what smart telescopes emit. All subs must share dimensions.
