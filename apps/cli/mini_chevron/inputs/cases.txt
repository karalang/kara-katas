# Mustache cases: each runs chevron.render(template, data, partials_dict,
# partials_path=None, warn=True). A block is the lines up to the next
# marker, joined with newlines; an empty last line gives a final newline.
=== interpolation: no tags
~~~ template
Hello from {Mustache}!
~~~ data
{}
=== interpolation: basic
~~~ template
Hello, {{subject}}!
~~~ data
{"subject": "world"}
=== interpolation: escaping
~~~ template
These characters should be HTML escaped: {{forbidden}}
~~~ data
{"forbidden": "& \" < > '"}
=== interpolation: triple mustache and ampersand
~~~ template
{{{forbidden}}} | {{&forbidden}} | {{& forbidden }}
~~~ data
{"forbidden": "& \" < > '"}
=== interpolation: numbers, booleans and null
~~~ template
int {{i}}, float {{f}}, big {{big}}, exp {{e}}, true {{t}}, false {{no}}, zero {{zero}}, fzero {{fz}}, negzero {{nz}}, null [{{nil}}]
~~~ data
{"i": 85, "f": 1.21, "big": 12345678901234567, "e": 1e3, "t": true, "no": false, "zero": 0, "fz": 0.0, "nz": -0.0, "nil": null}
=== interpolation: lists and dicts print as Python values
~~~ template
{{list}} / {{dict}} / {{{dict}}}
~~~ data
{"list": [1, "two", 3.5, null, true, ["it's"], {"q": "\"x\""}], "dict": {"a": 1, "b": [], "c": "line\nbreak"}}
=== interpolation: empty values

=== interpolation: missing key warns

=== interpolation: dotted names
~~~ template
